# 拾刻 Snapday｜项目说明

## 项目目标

把容易遗忘的活动海报、群通知截图，整理成用户确认过的活动与报名截止时间，再保存到时间线、导出到日历。

面向活动较多、通知来源分散的个人用户，支持逐张识别截图并累计保存多项活动，统一查看、搜索和导出。通过 OCR 预填与集中管理，减少反复翻找通知、手工抄录和逐条创建日历事件的步骤；节省时间是产品目标，具体耗时收益需通过后续对照测量验证。

核心流程：**上传截图 → 真实 OCR → 日期解析 → 人工核对 → 保存时间线 → 导出 `.ics`**。

本文说明首版功能范围、技术架构与验收标准。各项标准的实际验证状态及已知限制见 [QA.md](QA.md)。

## 首版范围

- 面向个人使用，手动上传一张清晰的中文通知截图；一张图对应一个主活动和一个可选截止时间。
- 展示原图、OCR 原文及可编辑卡片；卡片包含标题、地点、活动开始/结束时间、报名截止时间。
- 自动识别结果以草稿展示，用户核对并确认后才保存；未识别出的字段保持为空，由用户补充。
- 确认后保存至当前浏览器的时间线，并允许选择活动、截止时间导出日历文件。
- 仅对本工具保存的数据进行重复与冲突检查；缺少结束时间的活动不报告精确时段冲突。

不包含系统截图监听、后台推送、系统日历读取、账号同步、多人协作、爬虫、复杂重复日程和付费模型 API。用户需自行将导出的文件导入日历；日历提醒是否出现取决于导入软件和用户设置。

## 技术架构

首版采用无需构建的 HTML / CSS / ES Modules，处理流程都在浏览器中运行：

```text
用户选择截图
  → Tesseract.js 本地中英 OCR（chi_sim + eng）
  → 中文日期确定性解析与字段候选
  → 可编辑草稿 / 待确认提示
  → 用户确认
  → localStorage 时间线
  → RFC 5545 .ics 序列化与下载
```

OCR 脚本、worker、WASM 和语言包由项目静态资源同源自托管，不依赖 CDN。浏览器加载这些资源后在本机识别，不调用远程识别服务。本地处理的数据流可通过浏览器网络请求检查；相关验证状态见 [QA.md](QA.md)。项目通过静态 HTTP 服务运行，不支持直接双击 HTML 文件启动。

内置样例选择只加载真实图片；用户仍须点击识别按钮触发 OCR。另有粘贴文字通道，可直接进入日期解析与核对流程，但这条通道不验证图片识别。

当前版本使用确定性规则整理日期与字段，未接入 LLM；结构化语义理解属于后续扩展方向。

## 日期与数据规则

- 优先处理明确标注的“活动时间”“报名截止”和常见年月日、时分、时间区间；无法可靠判断时交给用户补充。
- 缺少年份、相对日期或时段含糊时，显示待确认状态。相对日期使用可见的参考日期和时区解释，最终日期由用户确认。
- 用户确认的完整日期是计算与导出的依据。首版按 `Asia/Shanghai` 解释和展示时间，导出时转换为对应的 UTC 时间。
- 结束时间若存在，必须晚于开始时间；缺失时保持为空，不自动填充默认时长。
- 有完整开始和结束时间的活动才参与精确冲突检查；区间采用左闭右开规则，相邻衔接不算重叠。截止时间不被当成有持续时长的活动。
- 重复候选按“条目类型 + 规范化标题 + 开始时间”判断，并显示提示供用户处理。
- 保存条目应保留稳定标识、条目类型、确认后的字段、时间来源及创建/更新时间，便于刷新恢复和稳定导出。
- `localStorage` 仅保存于当前浏览器；清除浏览器数据、换设备或换浏览器后不会自动恢复。

## 用户故事与验收标准

| 用户故事 | 首版验收标准 |
|---|---|
| 我想把一张活动截图变成事件 | 选择图片并执行 OCR 后展示识别原文，卡片由本次原文解析生成 |
| 我想同时记住活动与报名截止 | 两种时间分别展示，保存或导出时可区分活动与截止条目；缺失字段可以手动填写 |
| 我担心日期被识别错 | 原图、原文与卡片可对照；年份缺失或相对日期提示确认；确认前不自动保存到时间线 |
| 我想在下次打开时继续查看 | 确认保存后刷新页面，当前浏览器的条目仍存在；能修改和删除 |
| 我不想重复记录或安排撞车 | 同一已保存条目重复加入时有提示；完整时段重叠时有提示；缺少结束时间的活动不参与精确时段冲突检查 |
| 我想放进自己的日历 | 下载有效 `.ics`，导入后标题、地点、时间与确认卡片一致；重复导出保留同一事件的稳定 UID |

日历导出的验收范围包括 `VCALENDAR` / `VEVENT` 结构、UTC 时间、文本转义、CRLF 换行及 RFC 5545 所需的折行，以验证中文和标点内容的序列化兼容性。

## 扩展范围

当前版本聚焦截图输入、人工核对、本地保存及日历导出。更多截图类型的解析与智能语义去重尚未实现。
